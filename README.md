A simple gravity simulator made from scratch in PyGame. It was made in 2023 or 2024 and features custom circle-on-circle collision physics and gravity.

# Installation
- Clone the repository.
- Install requirements from requirements.txt using `pip install -r requirements.txt`.
- Run the app from the `main.py` file with `python main.py`.

# Controls
- Press space to start the simulation.
- Pan and zoom with the mouse
